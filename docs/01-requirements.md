# 01 — 要件定義

> darask-filer: Windows 11 向けエクスプローラー上位互換ファイラー。
> 本ドキュメント群は Claude Sonnet 5 が単独で実装を進めるための設計書である。
> 設計判断の根拠となった調査(2026-07-13 実施)の要点は各ドキュメントに埋め込み済み。

## 1. プロダクトの目的

Windows 11 エクスプローラーの**厳密な上位互換**。ユーザーがエクスプローラーで行っている操作は一つも壊れず、
そのうえで次の3点で圧倒的に勝る:

1. **速度** — 起動、フォルダー表示、検索、すべてが「即時」に感じられること。
2. **検索** — Everything (voidtools) 級のファイル名瞬間検索。インデックスは常に最新(USNジャーナル追尾)。
3. **履歴** — フォルダー別・ファイル別の操作履歴タイムライン(独自機能。エクスプローラーに存在しない)。

対象ユーザー: 日本語話者のパワーユーザー。日本語ファイル名・IME の完璧な動作は**絶対要件**。

## 2. ハード要件

### 2.1 速度(数値目標 — 受け入れゲートとして使用)

| 項目 | 目標 | 備考 |
|---|---|---|
| ウィンドウ表示(常駐状態から) | < 100 ms 体感 | 常駐プロセス + 事前生成の隠しウィンドウ |
| コールドスタート | 1–2 s 以内(worst) | R2R + ProfileOptimization。常駐が本命の保証 |
| 10万エントリのフォルダー表示 | Enter 後 < 300 ms で全面描画(SSD ウォーム) | M1 受け入れ基準(docs/07 M1 と定義を統一) |
| 10万行スクロール | フレーム落ちゼロ | ETW/PerfView で検証 |
| 検索(全マシン、1M ファイル) | 初回結果 < 100 ms 体感、p95 < 100 ms | デバウンスなし・打鍵ごと |
| 列ソート(10万件結果) | < 50 ms | 事前ソート済み順列配列方式 |
| 外部変更のタブ反映 | < 500 ms | USN 追尾 ~250 ms 周期 |
| 初回インデックス構築(1M ファイル) | 名前ベースライン ≤ 15 s(必須)/ 名前+メタデータ ≤ 60 s(ウォームキャッシュ・NVMe、M9 ゲート) | 名前検索はベースライン完了時点で可能。メタデータ補完はコールドだとディスク律速で伸び得るためバックグラウンド進捗表示で許容(docs/03 §3) |
| インデックス RAM | ≤ 150 MB / 1M ファイル | パック UTF-8 アリーナ必須 |
| UI スレッドブロック | > 5 ms でデバッグビルドは assert | Dispatcher watchdog |
| 対エクスプローラー比較 | 10万フォルダー表示 ≥ 5×(同一マシン・現行ビルド比) | M17 ベンチハーネスで恒常測定 |

### 2.2 検索

- 全ローカル NTFS ドライブのファイル名瞬間検索(Everything アーキテクチャの忠実な複製)。
- **正確さ** = インデックスの鮮度保証(USN 追尾 + ジャーナルラップ検出 + 再ベースライン)と、
  検索オラクルテスト(素朴な線形走査との10k件ランダム照合、日本語・全角半角・サロゲートペア含む)。
- クエリ文法: Everything 文法サブセット(空白=AND, `|`=OR, `!`=NOT, `path:`, `ext:`, `size:`, `dm:`)。
- ランキング: 完全一致 > 前方一致 > 単語境界 > 部分一致。フォルダーはブースト。クエリ延長時は前回結果を絞り込み再利用。
- 全角/半角同一視(NFKC折りたたみ: `ﾌｧｲﾙ`↔`ファイル`, `１２３`↔`123`)— 既定ON、設定で切替。折りたたみは検索用バッファのみ。元名は不変。
- コンテンツ(全文)検索は **v1 対象外**(LATER)。

### 2.3 エクスプローラー機能パリティ

詳細は §4 チェックリスト。方針:

- ファイル操作はすべて **IFileOperation**(本物のコピーエンジン: 進捗/衝突ダイアログ・ごみ箱・UAC昇格が無償で付いてくる)。
- 右クリックメニューは**本物の IContextMenu ホスト**(7-Zip, TortoiseGit 等のクラシック拡張が完全動作)。
- OLE ドラッグ&ドロップ双方向(Explorer/Outlook/ブラウザーと相互運用、仮想ファイル受け入れ含む)。
- 既知で受容するギャップ(明示): Windows 11 の MSIX 専用 IExplorerCommand トップレベル項目はサードパーティには
  ホスト不可能(公開APIなし。Files #8251 が2022年から未解決)。クラシック拡張(7-Zip/TortoiseGit/WinRAR)で実用は満たす。

### 2.4 履歴機能(独自の看板機能)

- **ファイル別タイムライン**: 作成・変更・リネーム・移動・削除・復元・オープン。
  **アプリ外(他アプリ・darask-filer 非起動中)の変更も USN ジャーナル経由で捕捉**。
- **フォルダー別履歴**: 「最後にいつ来たか」「ここで何が起きたか」。自分の操作 / 他アプリ / 全部のフィルター。
- リネーム・移動をまたいで履歴が追従(FileID ベースの同一性)。
- 正直さ: 捕捉できない期間(ジャーナルラップ等)は **gap イベント**として UI に明示。
- プライバシー: ローカルのみ・イベントのみ(内容は保存しない)・一時停止・除外グロブ・項目単位の忘却・全消去。

### 2.5 日本語 / Unicode(絶対要件)

- IME: リネームボックス・アドレスバー・検索ボックスでインライン変換・候補ウィンドウ位置・Tab変換が完璧に動くこと。
  実機 Windows 11 + MS-IME で、該当サーフェスが生えたマイルストーンごとに検証。
- ファイル名は UTF-16 end-to-end。NFC/NFD・全角・サロゲートペアのテストフィクスチャを CI に常備。
- ソートは `StrCmpLogicalW`(エクスプローラー同一の自然順、日本語対応)。
- UI 言語: 日本語ファースト(ja-JP 既定、en フォールバック)。.resx リソース方式。

## 3. 非目標(v1 で作らないもの)

- コンテンツ全文検索インデックス
- FTP/SFTP/クラウドアカウント統合(OneDrive はプレースホルダー対応のローカルフォルダーとして扱う)
- ネットワーク探索(ネットワークコンピューター一覧)。UNC パス直接入力は MUST。
- ライブラリ、desktop.ini の書き込み(読み取り=カスタムフォルダーアイコン表示は MUST)
- エクスプローラーのシステム既定置き換え(Win+E 乗っ取り)— レジストリハックが必要で危険
- タブのウィンドウ間ドラッグ / ティアオフ(v1 はタブ並べ替えまで)
- Recommended フィード、Gallery ビュー、AI アクション
- MSIX / ストア配布(HKCR 仮想化が ShellNew 等を壊すため意図的に非パッケージ配布)

## 4. エクスプローラー・パリティ・チェックリスト

凡例: **MUST** = v1 ブロッカー(毎日の筋肉記憶)/ **SHOULD** = v1.x 早期フォロー / **LATER** = 延期。
(2026-07-13 の競合調査 + Windows 11 25H2 Explorer 機能調査から作成)

### ナビゲーションとウィンドウ

- **MUST**: ナビゲーションペイン(クイックアクセス: ピン留め+並べ替え、PC、ドライブ、展開可能ツリー、ツリーへのドラッグターゲット、OneDrive ルート)
- **MUST**: タブ — Ctrl+T / Ctrl+W / Ctrl+Tab / 中クリックで閉じる / ドラッグ並べ替え / 右クリック「タブの複製」/ フォルダーを新しいタブで開く
- **MUST**: 戻る/進む/上へ(Alt+←/→/↑、マウス4/5ボタン、Backspace はエクスプローラー準拠)
- **MUST**: アドレスバー = パンくず(セグメントごとの ⌄ ドロップダウン)+クリックでパス編集(Alt+D / Ctrl+L / F4)、
  補完(自前インデックス供給)、環境変数展開(%USERPROFILE%)、引用符付きパス貼り付け、UNC 入力
- **SHOULD**: `shell:` URI(shell:sendto 等)、プログラム名入力で実行
- **MUST**: 検索ボックス(現在フォルダースコープ+グローバル)。SHOULD: フィルター文法、search-as-you-type(実際は v1 でやる — 検索は看板)
- **MUST**: ステータスバー(項目数・選択数・選択サイズ)、ダーク/ライト、日本語 UI、Per-Monitor DPI
- **SHOULD**: セッション復元(実際は v1 でやる — クラッシュ耐性の柱)、ローカル専用ホーム(クラウド照会は絶対にしない — Explorer の実証済み失敗)
- **LATER**: Gallery、詳細ペイン。デュアルペインは差別化機能として M14 で入れる

### ビュー・ソート・列

- **MUST**: 詳細 / 一覧 / 小〜特大アイコン、Ctrl+ホイールズーム、Ctrl+Shift+1..8
- **SHOULD**: 並べて表示(Tiles)、列ヘッダーのクイックフィルター。**LATER**: コンテンツ表示、Gallery
- **MUST**: 全列ソート(ヘッダークリック昇降)、`StrCmpLogicalW` 自然順 + 日本語照合、フォルダー優先
- **SHOULD**: グループ化(名前/種類/日付/サイズのバケット、折りたたみヘッダー)— 実装は平坦リスト+合成ヘッダー行(CollectionView 禁止)
- **MUST**: 列の追加/削除/並べ替え/リサイズ(最低: 名前・更新日時・種類・サイズ。作成日時・属性は SHOULD)
- **MUST**: フォルダー別ビュー設定の記憶(自前 DB、レジストリ Bags は使わない)
- **MUST**: 隠し/システム項目トグル、拡張子トグル、F5、**自動更新**(ReadDirectoryChangesW + USN 差分)

### 選択とキーボード

- **MUST**: フルキーマップ: Ctrl+A, Ctrl+Shift+N, F2, F5, Alt+Enter, Del / Shift+Del, Ctrl+C/X/V, Ctrl+Z/Ctrl+Y,
  Ctrl+Shift+C(パスのコピー), Shift+F10, Ctrl+N / Ctrl+W, F11, Alt+P, Tab/F6, Home/End/PgUp/PgDn, Enter
- **MUST**: 先行入力選択(IME 合成済み日本語でも動く)、ラバーバンド選択、Ctrl/Shift クリック、選択の切り替え

### ファイル操作

- **MUST**: コピー/移動は **IFileOperation**(本物の進捗ダイアログ、衝突ダイアログ「置換/スキップ/両方保持」、
  `- コピー` 命名、キャンセル)。バックグラウンドキューは SHOULD
- **MUST**: ごみ箱削除(Del)/完全削除(Shift+Del 確認付き)/復元
- **MUST**: **Ctrl+Z / Ctrl+Y** — rename/move/copy/new/delete の自前アンドゥスタック(delete の undo = ごみ箱復元。
  エクスプローラーの undo スタックは公開 API が無いため相互運用しない — 自前で持つ)
- **MUST**: F2 インプレースリネーム(拡張子を除く名前部を選択)、複数選択 F2 → `base (1)` パターン、
  リネーム中 Tab/Shift+Tab で次/前の項目へ(Win11 動作)
- **MUST**: 「新規作成 >」メニュー: フォルダー + **HKCR ShellNew** 列挙(テキストドキュメント等)
- **MUST**: 切り取り/コピー/貼り付けの Explorer 相互運用(CF_HDROP + PreferredDropEffect、cut 完了時の
  PERFORMEDDROPEFFECT / PASTESUCCEEDED 応答)
- **MUST**: OLE D&D 双方向(修飾キーで move/copy、ドロップカーソル)。右ドラッグメニューは SHOULD。
  Outlook 添付の受け入れ(仮想ファイル CFSTR_FILEDESCRIPTORW/FILECONTENTS)は M4 でやる
- **MUST**: ZIP: 全展開ウィザード + ZIP 作成。SHOULD: ZIP 内ブラウズ、7z/tar 作成(24H2 パリティ)、7z/rar/tar 展開(23H2 パリティ)
- **MUST**: アクセス拒否 → UAC 昇格リトライ(IFileOperation が無償提供)
- **MUST**: 長パス > 260(longPathAware マニフェスト + `\\?\`)。シェル拡張側の失敗は Explorer と同等の現実として文書化

### シェル統合

- **MUST**: 本物の **IContextMenu**(項目+フォルダー背景、クラシック拡張、タイムアウト+拡張ブロックリスト付き)、「ターミナルで開く」
- **SHOULD**: Win11 パッケージ版 IExplorerCommand の表面化(公開 API なし — 実現不能とわかっている。§2.3 の受容ギャップ)
- **MUST**: **送る**(shell:sendto)、**プログラムから開く**(+SHOpenWithDialog)
- **MUST**: シェル**プロパティ**ダイアログ(SHObjectProperties / SHMultiFileProperties — 再実装禁止。
  セキュリティ/詳細/以前のバージョンタブが無償で付く)
- **MUST**: .lnk 解決+起動(IShellLink)、ショートカット矢印オーバーレイ
- **MUST**: ShellExecuteEx 既定動詞で起動(ファイル関連付け)
- **MUST**: 正しいアイコン(desktop.ini カスタムフォルダーアイコン含む)+サムネイル(非同期・キャッシュ・UI スレッド禁止)
- **SHOULD**: アイコンオーバーレイ / OneDrive 同期状態(システム15スロット制限 — 状態列を優先)、
  プレビューペイン(IPreviewHandler — 実際は v1 M13 でやる)、取り出し、フォーマットダイアログ、ネットワークドライブ割り当て
- **LATER**: ライブラリ、desktop.ini 書き込み、共有シート、アイコンオーバーレイ完全パリティ

### 場所

- **MUST**: NTFS 固定/リムーバブル、UNC `\\server\share`、マップ済みドライブ、`\\wsl.localhost`、exFAT/FAT32 USB
- **SHOULD**: MTP(スマホ/カメラ)— シェル名前空間経路。v1 最低ライン: 一覧+コピーアウト、または明示的な
  「エクスプローラーで開く」フォールバックボタン(Explorer++ 最大の不満点なので受け入れ基準に含める)
- **MUST**: OneDrive プレースホルダー対応(列挙・サムネイルで**絶対にハイドレートしない** — `FILE_ATTRIBUTE_RECALL_ON_DATA_ACCESS` 尊重)
- **LATER**: ネットワーク探索、FTP/SFTP、システム既定ハンドラー化
